How Per-User Updates Work
  1. Targeting: Set the Target to ALL for global software updates, or pick a Specific School if only that school ordered or paid for the new module/feature.
  2. Automated Pull: When SoftBuilt Shield sends its heartbeat ping, it detects the update and pulls the authorized .zip package.
  3. Zero-Downtime Staging: Shield extracts, stages, and deploys the new code without touching the school's existing live MySQL database records.
School Data Privacy

Updates only transfer application source code (.php, .html, .js, .css, asset files). School attendance, student identities, and billing databases remain 100% on their local machine.
